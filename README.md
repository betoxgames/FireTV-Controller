# Pasos de instalación

1. [Descarga la última versión](https://github.com/betoxgames/FireTV-Controller/releases/latest) y descomprime el ZIP.
2. Abre `ControlRemoto.app`. Si falta ADB, acepta su instalación desde la propia aplicación.
3. Activa la depuración ADB de tu Fire TV, asegúrate de que ambos dispositivos estén en la misma red e introduce la IP de tu TV en el engrane.

Requiere macOS 13 o posterior.
